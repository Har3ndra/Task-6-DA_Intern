# Sales Trend Analysis Using SQL Aggregations

## Project Overview

This project focuses on analyzing monthly sales trends and order volume using SQL and MySQL.

The objective is to transform transaction-level sales data into meaningful business insights by analyzing revenue and order volume across different months.

This project demonstrates practical SQL-based data analysis and aggregation techniques used by Data Analysts.

## Dataset

The project uses an Online Sales Data dataset containing transaction-level sales information.

### Dataset Features

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Date | Date of the transaction |
| Product Category | Category of the product |
| Product Name | Name of the product |
| Units Sold | Number of units sold |
| Unit Price | Price per unit |
| Total Revenue | Revenue generated from the transaction |
| Region | Region where the transaction occurred |
| Payment Method | Payment method used |

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- CSV Dataset

## Project Objectives

The main objectives of this project are:

- Analyze monthly revenue
- Calculate monthly order volume
- Identify the highest-revenue month
- Identify the lowest-revenue month
- Analyze sales trends over time
- Analyze sales performance for specific time periods
- Generate meaningful business insights from transaction data

## Analysis Performed

The project includes the following analyses:

### Monthly Revenue Analysis

Monthly revenue was calculated by grouping transactions based on year and month.

### Monthly Order Volume

The number of unique orders was calculated for each month to understand changes in customer purchasing activity.

### Revenue Trend Analysis

Monthly revenue was compared across the available period to identify increases, decreases, and fluctuations in sales performance.

### Highest Revenue Month

The month generating the highest total revenue was identified.

### Lowest Revenue Month

The month generating the lowest total revenue was identified.

### Time Period Analysis

Sales performance was also analyzed for selected time periods to understand revenue and order-volume behavior within specific date ranges.

## Key Insights

- January 2024 recorded the highest monthly revenue at **14,548.32**.
- July 2024 recorded the lowest monthly revenue at **6,797.08**.
- Revenue generally declined after January 2024.
- March and April showed relatively strong sales performance.
- Revenue declined considerably between May and July.
- August showed a slight recovery compared with July.
- Order volume remained relatively stable across most months.
- The variation in revenue despite relatively stable order volume suggests that transaction value played an important role in overall revenue changes.
